# Rook/CephFS trial manifests (archived)

These are the Flux Kustomizations and Kubernetes manifests for the
Rook/CephFS storage trial described in
[`../git_storage_latency_and_ha.md`](../git_storage_latency_and_ha.md).

All Flux Kustomizations were suspended and the trial completed on
2026-07-17. The manifests are kept here as reference for the storage
benchmark writeup. They are **not** wired into the cluster's
`cluster/k8s/kustomization.yaml` and will not be reconciled by Flux.

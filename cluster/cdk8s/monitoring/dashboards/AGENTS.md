# Grafana dashboards

Read and follow the [Grafana skill](../../../../grafana/skill/SKILL.md) before creating
or changing a dashboard. It owns SDK authoring, datasource mappings, credential consent,
candidate screenshots, and post-merge verification.

Use the shared builders in `foundation.py` for local dashboards. Follow the
[visual-test guide](../../../../grafana/visual_tests/README.md) for isolated PR screenshots.

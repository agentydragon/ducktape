# Test tiers

Decided by the operator, 2026-10-21. A test runs in the cheapest tier that has the real thing it depends on.

| Tier      | What is real                                                                                                                                                       | What it tests                                                                                                                                                |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Unit      | the code, in process                                                                                                                                               | pure logic                                                                                                                                                   |
| Component | one service, PostgreSQL in Docker, an envtest API server ([`kubernetes_apiserver.py`](../testing/kubernetes_apiserver.py) mints Pod-bound tokens), real neighbours | RBAC, watches, admission, token review, a service's API and storage; a neighbour is faked only to inject a fault                                             |
| Harness   | the Go runner, Claude Code and Codex, a scripted model                                                                                                             | harness protocols, Codex code mode included                                                                                                                  |
| System    | the [k3s stack](../x/k3s_env/README.md) with the scripted model                                                                                                    | every acceptance scenario: what needs a kubelet (running Pods, PVCs, suspend/resume, egress networking, LLM ingress identity) or several services; CI on PRs |
| Live      | a deployment with real models                                                                                                                                      | only where the model's behavior is under test ([acceptance README](../acceptance/README.md))                                                                 |

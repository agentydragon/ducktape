# GNOME Shell Keybindings

Pop Shell on GNOME 49, horizontal workspaces. Configured in
`gnome-shell-keybindings.nix`, based on Pop Shell's
[configure.sh](https://github.com/pop-os/shell/blob/master_noble/scripts/configure.sh)
adapted for horizontal workspaces.

## Window Focus (Pop Shell, hjkl only)

| Shortcut  | Action      |
| --------- | ----------- |
| `Super+h` | Focus left  |
| `Super+j` | Focus down  |
| `Super+k` | Focus up    |
| `Super+l` | Focus right |

## Workspaces

| Shortcut                 | Action                               |
| ------------------------ | ------------------------------------ |
| `Super+Left/Right`       | Switch workspace                     |
| `Ctrl+Alt+Left/Right`    | Switch workspace (classic)           |
| `Super+Shift+Left/Right` | Move window to workspace             |
| `Super+Shift+Up/Down`    | Move window to workspace (Pop Shell) |

## Window Management

| Shortcut       | Action             |
| -------------- | ------------------ |
| `Super+Return` | Enter tiling mode  |
| `Super+m`      | Toggle maximized   |
| `Super+comma`  | Minimize           |
| `Super+q`      | Close window       |
| `Super+y`      | Toggle auto-tiling |
| `Super+g`      | Toggle floating    |
| `Super+o`      | Toggle orientation |
| `Super+s`      | Toggle stacking    |
| `Super+/`      | Launcher           |

## System

| Shortcut       | Action        |
| -------------- | ------------- |

| `Super+e`      | Email         |
| `Super+b`      | Browser       |
| `Super+t`      | Terminal      |
| `Super+v`      | Notifications |

## Methodology

1. Extracted all `py_library` target names from every `BUILD.bazel` in the repo
2. For each target `//pkg:name`, grepped all other BUILD files for `:name` or `//pkg:name` in deps
3. For each target's source files, grepped all Python files for `from pkg.name import` or `import pkg.name`
4. Targets with zero hits in both searches were flagged as dead
5. Manual review excluded `py_binary` entry points, dynamically-loaded files (Alembic, Invoke), and targets where the name differs from the module name

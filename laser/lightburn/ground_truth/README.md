# LightBurn Geometry Ground Truth

SVG exports from LightBurn of test `.lbrn2` files generated by `//lightburn/ground_truth:generate_test_docs`.

These establish ground truth for how LightBurn interprets coordinates, text anchors, rotation, scaling, mirror flags,
and layer colors.

## Regenerating

```bash
bazel run //lightburn/ground_truth:generate_test_docs -- /tmp/test_docs
```

Then open each `.lbrn2` in LightBurn, export as SVG, and copy here.

## Files

| File                  | Tests                                                        |
| --------------------- | ------------------------------------------------------------ |
| `test_anchors.svg`    | HAlign x VAlign text anchors, non-rotated and rotated 90 CCW |
| `test_xform.svg`      | Coordinates, rotation, scale/mirror via XForm, layer colors  |
| `test_mirror_off.svg` | Labeled markers with `MirrorX=False, MirrorY=False`          |
| `test_mirror_on.svg`  | Same content with `MirrorX=True, MirrorY=True`               |

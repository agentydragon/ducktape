The **44 observed disagreements** prevent certifying strict preservation of the observed entry namespace or function descriptors for the **actual Rust output**. All 31 descriptor changes are within the 44. The other 78 show neither measured disagreement; that is not proof of equivalence. This is a lower bound on incompatibility under observables that include namespace membership and function own descriptors. It does not quantify what would be compatible under a different API contract. Under the authored expectations, Rust passes its different, explicit expectations. Case `residual_export_alias_collision` adds `av$1` while preserving the public alias `av`: a source-oriented implementation could hide the additional glue, but it would then emit a different public namespace than that Rust artifact.

Extra observation routes, stronger lowering, cell plumbing and valid scheduling are implementation obligations, not evidence of inherently incompatible semantics.

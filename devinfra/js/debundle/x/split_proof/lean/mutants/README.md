# Callback guard mutation checks

The test-only `translate` targets compile the production checker with specific edits to `Lower.lean`: remove the `unobserved` condition from either the identity-call or closure-factory inference, omit deferred references, omit inert alias references, or omit both inert alias references and the independent inert-initializer ordering guard. The Bazel generation step fails if the expected source guard is not present exactly once. These are deliberately unsound executables; production targets do not depend on them.

`//devinfra/js/debundle/x/split_proof/experiments/translation:callback_mutation_test` runs the generated callback corpus with seeds 1 and 2026 against the original and each mutant. Every run must complete all direct/plain/object/array-alias and global/local-slot cases. Safe orderings must be accepted and match Node; unsafe orderings must differ under Node. The original must reject every unsafe ordering. Removing either call-specific guard must yield wrong accepts for direct reads; removing deferred-reference collection must do so for both call families. Removing alias-reference collection alone currently produces no wrong accepts in this corpus because the inert-initializer guard independently protects the alias. Removing both protections must yield wrong accepts for plain and object/array aliases in both families. Unexpected checker exits, harness errors, incomplete corpus or a surviving required mutant fail the test.

This is a sensitivity check for these mutations and generated examples. A surviving individual alias mutant is recorded evidence of overlapping protection in this corpus, not proof that the omitted check is unnecessary; none of these tests proves the checker sound.

The separate `no_writes` test-only checker erases the computed write footprints. `ast_write_mutation_test` runs generated AST programs with seeds 17 and 2026 against it and the real checker; the test inspects the generated AST and pairing as well as the two successful Node outputs for an accepted read moved before its increment. This measures one write-footprint mutation, not all write forms or all possible seeds.

# Property access and local-constructor effects

`PropertyRead.lean` models one property of an argument and one of a receiver. Each has an own and one inherited slot, with data-property writability or optional getter and setter. A getter or setter appends a marker and may return or throw. A strict write to a non-writable data property or an accessor without a setter throws; a write through an inherited writable data property creates an own writable property on the receiver. A thrown getter stops the subsequent write. These behaviors are modeled, not proved against ECMAScript.

`initialize_preserves_trace` now proves **normal completion and unchanged trace**, not just unchanged trace, when the actual read path has no accessor and the receiver has an own writable data slot. It permits a changed receiver value. Those facts are premises about the supplied states, not inferred from the JavaScript input or preserved across earlier calls. The MiniJS composition theorem also requires a known closure identity and a successful MiniJS evaluation.

The axiom test checks concrete inherited getter and setter effects, throwing accessors, non-writable own and inherited properties, absent setters, and creation of an own property through an inherited writable data descriptor. Reading a missing property or accessor with no getter yields zero as a placeholder for JavaScript `undefined`, not an exact value representation.

This is neither an ECMAScript semantics nor MiniJS object semantics. In particular, the receiver is assumed to be an extensible ordinary object, and getters and setters are reduced to one marker and a return/throw choice; proxy traps, arbitrary accessor behavior and values, multiple prototype levels, heap aliasing, allocation failures, reentrancy, full exception identity, JavaScript parsing and module evaluation are absent. The composition theorem runs separate MiniJS and property-model computations, not a JavaScript function body. A sound JavaScript bridge must justify each modeled condition and preserve dependencies, exceptions and observable behavior. This experiment does not change checker acceptance or discharge Tana obligations.

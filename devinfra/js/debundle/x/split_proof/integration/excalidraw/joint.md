# Historical Excalidraw deployment replay

The certified browser target is retired. This page records its earlier structural
replay and is not a current strict certification or CI gate. Re-enable a browser
test only when the production source/spec constructor emits a small pinned real
Excalidraw placement under the stated strict observation contract, its files pass
a separate disk recheck, and Chromium exercises an observable result from those
files.

One [ownership subset](../../../../excalidraw/deployment_smoke_subset.json)
selected `strokeEllipseWithRotation` from main and 365 editor bindings. Rust
exported canonical and selected placements from the same selector solve. Lean
checked their source digests and original unit identities, staged both splits
and the seven fixed static providers, reparsed the complete output, and
certified one modeled initialization schedule rooted at `main.js`.

The historical proof checked both original public namespaces under the recorded
browser-page, native metadata, stable `Math.PI@1`, and empty import-map
premises. A separate disk check verified the same deployment. Chromium loaded
the original and checked trees in fresh contexts, exercised drawing and undo,
and checked extracted renderer, editor, and geometry functions. Lazy files
outside the static overlay resolved against the original bundle.

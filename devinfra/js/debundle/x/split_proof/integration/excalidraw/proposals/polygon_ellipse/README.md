# Polygon and ellipse helpers in the pinned editor

The [named selection](named_delta.json) adds six declarations from [`packages/math/polygon.ts`](https://github.com/excalidraw/excalidraw/blob/v0.18.1/packages/math/polygon.ts) and three from [`packages/math/ellipse.ts`](https://github.com/excalidraw/excalidraw/blob/v0.18.1/packages/math/ellipse.ts). The [joint Rust resolution](https://app.buildbuddy.io/invocation/5dfee98c-1183-4485-81cd-a5ee73e1721a) on production SHA-256 `fa1cfc7930fe3c0e2b4d95e6cb14ebde21068014cd92db303622509d9a0d455c` places exactly nine previously unowned units; the other 1,778 units retain their ownership from the 353-binding placement.

| Source declaration                                                                     | Production match and use                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `polygon`, `polygonFromPoints`, `polygonClose`, `polygonIsClosed` (530, 531, 534, 535) | The rest-parameter and array constructors call the same close helper. It returns an already-closed array by identity, or appends its first point after comparing the endpoints with `pointsEqual`. [Shape construction](https://github.com/excalidraw/excalidraw/blob/v0.18.1/packages/utils/geometry/shape.ts#L126) calls the constructors.                                                                                                                                                                                                                                                                                                 |
| `polygonIncludesPoint`, `pointOnPolygon` (532–533)                                     | The ray-crossing loop toggles a boolean on a crossing. The edge test iterates adjacent points up to the last segment and passes a tolerance to `pointOnLineSegment`. [Collision testing](https://github.com/excalidraw/excalidraw/blob/v0.18.1/packages/utils/collision.ts#L30) uses the edge test and the containment test for different questions.                                                                                                                                                                                                                                                                                         |
| `ellipse`, `ellipseDistanceFromPoint`, `ellipseLineIntersectionPoints` (1147–1149)     | The constructor preserves center and half-axes. The distance helper refines a point three times, restores component signs and measures Euclidean distance. The intersection function translates into ellipse coordinates, solves the quadratic for the infinite line and collapses coincident tangent points. [Element distance](https://github.com/excalidraw/excalidraw/blob/v0.18.1/packages/excalidraw/element/distance.ts#L118) and [element collision](https://github.com/excalidraw/excalidraw/blob/v0.18.1/packages/excalidraw/element/collision.ts#L308) construct ellipses with these same half-width and half-height conventions. |

Changing the ellipse refinement count from three to four produces [`no_match`](https://app.buildbuddy.io/invocation/298866bc-9f22-4d23-9ad2-b3757f294afa) on those same bytes. The delta makes no claim for the upstream segment-intercept or ellipse inclusion/touch helpers. Its point, vector and segment dependencies are already present in the baseline.

The original replay added [polygon.yaml](polygon.yaml) and [ellipse.yaml](ellipse.yaml) to `selected_editor_placement.proposal_fragments` under `packages/math/polygon` and `packages/math/ellipse`. It appended the two entries in the named delta to a copy of the baseline selection and kept the existing owner priority and all other fragments. The browser smoke supplied the resolved artifact to `lowersplit --resolved-placement editor`, with the browser deployment origin and the baseline `browser-page` / `Math.PI@1` contract.

[353 + 9](https://app.buildbuddy.io/invocation/cd7a4b8d-ff62-4055-a8d3-fc6250f5a0ee) and [355 + 9](https://app.buildbuddy.io/invocation/d757109d-a1c0-4d0f-8e66-48f10f9c9b12) both passed normal-completion certification, a separate `--check-output` run and Chromium, retaining the original editor's 611-name public namespace. In the split editor, the probe closed an open square, preserved a closed ring's identity and distinguished interior, exterior and boundary points. For the ellipse centered at the origin with half-axes 2 and 1 it checked two secant roots at x = ±2, one tangent intersection, no intersections outside, and distance 1 (within 1e-4) from (3, 0).

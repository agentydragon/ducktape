## Controls to preserve through adoption

- Independent tiny subset/import-list oracles establish soundness and
  completeness for the advertised append-one-owner, baseline-preserving family.
  Production constructs atom-closure SCC/event-bound summaries once, expands the
  selected closure and certifies it once; no per-seed full graph copies, subset
  enumeration or arbitrary schedule-existence solver.
- Ordinary and selected-view CLI proposal/check/preview/apply/Node tests retain
  full-base semantic premises and selector anchors. Plans bind source identity,
  complete ownership and import priority together. Graph-only checks return no
  executable plan; selector-writer refusals are distinct from graph exhaustion.
- Retain rejected-priority, required-companion, rebinding, anonymous-unit,
  selector ambiguity, stale-input, omitted-anchor and no-write controls. Cover
  default destinations, configured physical roots, several captured chunks,
  relocation and input invalidation. Recheck combined plans.
- Distinguish local tests, exact-head hosted checks, merge state, adopted pin and
  emitted behavior. An interrupted analysis is inconclusive, not a completed
  negative. No report-only or graph-only success replaces the normal gate.

# Local and imported analysis parity

The accepted implementation contract: an input chunk boundary must not discard
facts available to the equivalent local analysis. This applies to the currently
modeled operations under the same abstract inputs, initialization phase, declared
assumptions and resource limits. An execution-dependent conclusion is not a
globally valid source fact.

## Completion

- Keep the current realizability gate authoritative. The effect-verdict flip
  and producer replacement remain separate work.
- Extract the pinned Excalidraw icons into their upstream module, without
  absorbing unrelated residual code or adding semantic promises.
- Preserve normal source-order ESM output, live bindings, TDZ, abrupt
  completion and observable evaluation order.
- Prove each supported local transfer family through a corresponding real-CLI
  imported-code case. Direct and saved analysis must agree.
- Reject the cyclic global observer that changes `undefined` to `function`,
  while the unchanged canonical Excalidraw reconstruction passes.

## Implementation sequence

1. Capture the local transfer inventory and executable positive/negative
   baselines. Every case gives the CLI source plus a spec, then checks emitted
   execution/properties or a structured refusal. A diagnostic rejected tree is
   never an accepted result.
2. Build one immutable program link index from prepared manifests. Qualify
   bindings, callable and heap source identities by module. Resolve import
   aliases, reexports and static namespace references; preserve ambiguous,
   cyclic, missing and unsupported outcomes.
3. Retain executable provider definitions from the canonical preparation.
   Local and imported operations consume the same transfer interface, with
   evaluated operands, captured/live cells and caller-owned heap state.
4. Memoize conditional transfers with their complete read dependencies and
   state changes. Replay fresh allocations with distinct activation identity;
   preserve callback publication, retention and escape. Recursive or exhausted
   queries conservatively retain effects and record the loss.
5. Record availability conditions independently of callable behavior. Check
   them against the original and actual planned emitted ESM schedules, using
   the gate and emitter's shared import plan. A provider's eventual initialized
   state is not an early-cycle proof.
6. Route current purity, callback, binding-timeline and heap-order consumers
   through the shared results and remove the imported paths they replace.
   Author premises retain separate provenance.
7. Preserve completed facts, portable identities and proof dependencies in
   saved analysis. Reject stale provider/import/premise/vendor inputs.
8. Follow remaining Excalidraw icon witnesses, reduce each additional blocker,
   implement its missing general semantics and verify the upstream extraction.

## Executable matrix

Vary local, shared-provider, separate-provider, aliased, reexported and namespace
access. Compare each original program with its own emitted program; arbitrary
ESM inlining is not an equivalence law.

| Family            | Positive                                             | Negative                                                                          |
| ----------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------- |
| Availability      | Independent const callable beside other declarations | Changed early `var`, lexical or class observation                                 |
| Calls             | Transitive helper chain                              | Lost nested read, write or throw                                                  |
| Provider state    | Ordered `next` and `peek` with live cells            | `1 1` becomes `1 0` after the proposed split                                      |
| Returned heap     | Usable fresh records, arrays, closures and aliases   | A later shared mutation loses its identity                                        |
| Callbacks         | Deferred creation and later invocation               | Synchronous callback, getter or coercion observes a later cell                    |
| Captures          | Closure observes a later captured-cell update        | Summary freezes a live capture                                                    |
| Native operations | Same guarded local operation across imports          | Native identity, descriptor or prototype mutation invalidates it                  |
| Cycles            | Valid hoisted-function cycle                         | Direct, transitive, namespace, reexport or global observer changes initialization |
| Evaluation        | Operand order and caught errors preserved            | Changed callee selection, throw or preceding effect                               |
| Unknown execution | Safe co-location                                     | Dropped values, escaped callbacks or budget exhaustion erase effects              |
| ESM placement     | Legal setter/state ownership                         | A writable local becomes a read-only import                                       |

Include equal source offsets in different modules, shared providers, recursive
components and repeated allocations. Saved-analysis cases cover successful and
refused splits and dependency invalidation.

## Exit evidence

The local transfer inventory is closed; positive and adversarial e2e cases pass;
maintained passing specifications preserve acceptance; source and emitted runtime
checks agree; the canonical icon layout and browser interactions pass; and RBE
cost/RSS measurements quantify the change. No temporary imported evaluator or
unfinished alternate path remains. Each independently reviewable slice lands
with its tests; an intermediate slice is not completion of this plan.

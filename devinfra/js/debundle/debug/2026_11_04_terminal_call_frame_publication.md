# Terminal-call frame publication probe

A neutral CLI reproduction forwards a label into a record factory through a
concise arrow. Its record contains a callback capturing the label, an async
callback, and an array containing an enum own-field read. Two indirect calls
precede an annotated direct call of the same factory. All declarations belong
to one logical module so an unrelated placement conflict does not obscure the
execution report.

On base `02d9d16543`, the later direct call loses its factory proof and becomes
impure. Original and emitted Node execution both print `169 0`. The regression
fails at the later call's purity assertion in BuildBuddy invocation
`429aba68-e23b-4594-9f9f-8bd8a0cb673b`; the 27 existing tests pass.

The ordered call transfer already absorbs the incomplete child's effects. Its
second fallback publishes the entire caller frame, including the selected
factory. A terminal return has no remaining caller operation to summarize.
The probe stops that exact callable-body shape after a directly selected
singleton ordinary local function returns a partial value transfer. It keeps
all child effects, losses and uncertainty and widens returns to unknown normal
or abrupt completion. It grants no effect coverage.

The regression requires a later direct factory proof while both indirect calls
remain incomplete. Controls keep nonterminal suffix publication, child
self-publication and an earlier genuine escape conservative. Unknown targets,
operand failures and missing results retain the existing fallback.

This is a bounded repair probe. Passing public controls does not establish the
cause or acceptance of any downstream corpus; a matched downstream trace must
identify the first factory publication and validate the resulting behavior.

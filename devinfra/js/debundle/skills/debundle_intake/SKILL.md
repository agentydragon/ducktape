# Debundle Intake

Use the checked placement plan, matching graph and source, and project
conventions to [prepare one seed packet](references/docs/planning.md#prepare-seeds)
in the adapter's scratch directory. Intake reviews source and writes the
packet. Workers own YAML edits, gate runs and regeneration.

Keep companion moves together. Attach destination evidence, suggested names
and unresolved questions. Return a changed destination to planning for a new
complete check. Route broad ownership questions to the architect and tooling
blockers through the [bug reproduction workflow](references/docs/bug_reproductions.md).

# `debundle` CLI surface

The canonical reference for the `debundle` CLI lives in
[`guide.md`](./guide.md), which is the doc bundled into the role-based
skill packages under `devinfra/js/debundle/skills/`.

See `guide.md` for:

- Pipeline mode (`debundle run`).
- Binding queries and edits (`debundle binding describe|show-code|assign|unassign`).
- SCC queries (`debundle scc`).
- Cluster queries (`debundle cluster`).
- The legacy planning surface (`debundle peel ...`).
- Recipes and common-input wiring.

Design discussion of the pipeline half lives in `README.md` and
`DESIGN.md`.

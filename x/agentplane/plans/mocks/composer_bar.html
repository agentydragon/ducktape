Status dot states

Two independent state machines — session attachment (status) and the harness process (state.harness) — collapse into one dot. Worst axis wins; first match in the table below decides it.

Healthy
Attached, harness running.
Attached · Harness running
Pending
Still connecting, reconnecting, or attached with no harness report yet.
Reconnecting…
Idle
Stream ended, or the harness was shut down on purpose.
Stream ended · Harness stopped
Error
Harness lost, or the runner reported an error.
Harness lost
Condition (first match wins) Dot
1 status starts with "runner: ", or harness === "lost" Error — red, static
2 status is "connecting" / "reconnecting", or attached with harness === null Pending — amber, breathing
3 status === "stream ended", or harness === "stopped" Idle — gray, static
4 otherwise — attached and harness === "running" Healthy — green, static

Behavior notes

  • The menu is a Mantine Menu anchored to the "more" button. It floats via Floating UI, which flips placement on its own — the composer sits at the bottom of the viewport, so it opens upward here, not below the trigger; that's the library's default flip behavior, not something to hand-code. Closes on outside click, Escape, or picking an item.
  • "Raw frames" stays open after toggling (closeOnItemClick={false}) so flipping it shows the switch move without having to reopen the menu to confirm.
  • "Shut down harness" is disabled exactly when it is today — state.harness !== "running" — and probably wants a confirm step now that it's one tap more casual to reach.
  • The status dot picks one of four buckets by priority (see the states table above) rather than a literal cross-product of session/harness values — a plain function of the two, easy to unit-test on its own.
  • The tooltip carries the breakdown the two badges used to spell out — same role="img" + aria-label + Tooltip pattern already used for the transcript's streaming/failed/sending dots, and "Pending" reuses that same dot's breathing animation.
  • Interrupt's color is the only thing that changes with state — neutral and disabled when idle, danger-tinted and enabled the moment a turn starts, so "there's something to stop" reads before the operator reads the label.

Method and limits

  • The original audit inspected its stated commit; the 2 November status refresh inspected commit 2cbcf945b203. The 4 November PT / 5 November UTC review checked the five surviving findings against 79a2524e7fc and inspected PR #11497; it did not rerun Bazel queries.
  • The dated remote queries listed evaluated filegroup rules across //.... A source inventory also parsed literal top-level BUILD declarations; macros, selects, generated rules, load-time expressions and non-Bazel callers require additional review.
  • The latest repository-wide filegroup/reverse-dependency scan and focused wrapper query were run on 2 November at commit 2cbcf945b203. The focused query found no incoming rule edge for the four recorded labels, including M. This result is historical for that evaluated workspace, not a query result for the 4 November tree. See the linked invocation IDs in the evidence below.
  • Do not remove visual harness filegroups just because their labels are absent from BUILD files: agentplane_visual_test references them in its Starlark macro. Whole-program lint source groups are active inputs, and generated output groups or single-file views can be needed for $(rootpath).
  • These are selected high-signal cases, not an exhaustive proof that all other targets are correct. Priorities express review value and expected blast radius, not measured build-time savings. The original audit did not implement its recommendations; the status notes record subsequent work.

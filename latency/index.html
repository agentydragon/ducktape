A tested recommendation, with a failed variant retained

Hypothesis: repeated snapshot creation/verification hashes and copies the CLI executable, so symbol-table bytes increase e2e cost. cli/snapshot.rs streams SHA-256 during copying and independently verifies the stored engine. The experiment changes only the CLI’s rustc_flags; it keeps all inputs, six tests, integrity checks and relocation assertions.

3 · Measured experiment · Defer

Combining Nix evaluation is a small opportunity.

The docs wheel gate spends 20s on generated policy checks and 30s on the final imports step. A bounded experiment evaluated the three policy and ten package derivations separately and together. Every derivation path matched; combining saved only 0.91–1.28 CPU seconds across three repetitions.

If implemented, append all three checks to the existing final nix build --impure after artifact override assembly. Keep missing-output failures and every imports check. The experiment used pinned artifacts, not fresh PR overrides, and did not run builds. It cannot turn the 50s observed step total into a savings claim. A hosted comparison with real overrides is needed before prioritizing this change.

No capacity or packaging change recommended. All 27 recent PR Bazel jobs started within three seconds of job creation. The prior prepared-container experiment was slower than Nix setup. Neither current evidence nor the new evaluation spike justifies changing that conclusion.

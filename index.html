The sharding spike used source merge 05bb56825852a668524753f986b7912dee52c23d, with fresh test execution and normal RBE/cache settings. Analysis fell 63.67s → 1.52s between the sequential invocations; that is why their 137.6s elapsed-time difference is not a sharding saving. Worker time sums the remote worker lifecycle across all test shards, counting parallel workers separately. Process execution sums were 679.78s → 936.05s; CPU-seconds were 1330.4 → 1812.6. These are different resources, not additive or GitHub runner billing units. Queue-to-worker-start totaled under half a second in each run.

Do not remove test/build coverage to save a second.

The second bazel build took only 0.54–1.79s in these ten jobs. Removing it cannot provide a minute-scale gain. The tests, lint, source verification, trust checks and remote execution remain in every recommended experiment.

Do not equate the log stream opening with VM readiness.

For nine jobs with explicit runner timestamps, remote-step start to repository sync was 5.8–15.8s, and repository sync to driver start was 7.6–10.0s. The displayed “Waiting for available remote runner” interval includes batched log delivery; it is not a direct allocation measurement. No capacity or runner-image change is justified by these samples.

Defer cross-run base-hash caching.

On the controlled warm workload, both hashes plus checkout and target queries took 16.46s in total. Caching only the base hash therefore saves less than 16.5s here; the older plan’s 25–35s per hash is not a current warm-case estimate. The ten jobs used eight distinct base SHAs, which establishes some reuse but not a reliable cache hit rate.

If revisited, use exact base SHA plus generator/runtime fingerprints, trusted producer-only writes and regeneration on any miss or invalid entry. That correctness and transport work is disproportionate to the currently bounded saving. No cross-run cache was implemented or benchmarked. Root selection also excludes nested Bazel modules via .bazelignore; caching does not repair that independent coverage gap.

# base-sync

The ducktape commit you last reconciled your base (`haku/base/`, `haku/run.md`)
against — the SHA plus a one-line note. On the first run, set it to the current
ducktape `HEAD`; each run, diff `HEAD` against it and migrate your state to any
changes. See `instructions.md` → _Adopting base updates_.

_pin: (unset — first run)_

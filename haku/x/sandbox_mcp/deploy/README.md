# Retired sandbox deployment snapshot

`legacy-resources.yaml` is a snapshot of the Haku-specific `SandboxTemplate`, `SandboxWarmPool`,
cleanup policy, and Console Role/RoleBinding formerly generated by
`cluster/cdk8s/haku/workspaces.py`. The image is pinned to the last generated tag in this snapshot.

This Kustomize package is retained for reference and is not included in any Flux source or active
root. The active chart no longer emits these resources; Flux prunes them, including the pool-owned
idle Sandbox. Do not apply this package to restore the old lane. The warm-pool feature is explicitly
not being ported, and the old Role grants Console access to sandbox Pods and `pods/exec`.

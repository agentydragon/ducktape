# GitHub Pages

Follow [README.md](README.md) for this branch's publication and presentation conventions.

When adding, removing, or changing a report, check the root `index.html` and update it in the same PR as needed. Keep report titles, descriptions, observation dates, and links to reports and evidence accurate. Keep the report listing in `README.md` consistent too.

When answering follow-up questions about the cluster storage report that it does not yet address, update the report with the answers and their evidence alongside the response. Date observations and preserve relevant uncertainty.

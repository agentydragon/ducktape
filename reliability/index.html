Coverage, denominators and remaining uncertainty

Populations and limits
  • Shared GitHub census with the latency report: 3,871 runs, 1,513 core runs, 4,565 core job attempts; all attempts and conclusions retained. Whole-workflow conclusions are never substituted for Bazel verdicts.
  • Mainline population: 66 completed test invocations of 125 devel push runs, linked by deterministic ID with tested SHA equal to the push head. PR population: 225 invocations of 582 attempts; the 357 unresolved attempts are skipped fork runs or runs cancelled before Bazel started, confirmed by the job records.
  • Target exposure uses BuildBuddy target history since window start; fresh executions are first appearances of a (duration, status) pair, cache hits repeat the pair exactly; FAILED_TO_BUILD labels are downstream consequences and excluded from per-target frequencies.
  • Remote-error classification is by the first ERROR: line of each invocation log (ANSI stripped); 6 logs whose first line is a progress line remain ambiguous and are not counted as infrastructure.
  • No same-source recovery fraction is claimed: no failed target was re-run on the identical SHA in this window. No workflow, retry policy or test was changed or re-run by this analysis.
  • Raw logs, payloads and profiles stay local; the evidence file keeps invocation IDs, tested SHAs, counts and classifications.
  • Presentation: Pico CSS 2.0.6 and Chart.js 4.4.1 from cdnjs; without network the page still reads as plain HTML and every chart's numbers are repeated in the adjacent text or table.

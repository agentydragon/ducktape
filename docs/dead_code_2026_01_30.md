## Methodology

1. Extracted all `py_library` target names from every `BUILD.bazel` in the repo
2. For each target `//pkg:name`, checked reverse BUILD dependencies and executable/package closures
3. For each target's source files, searched Python, configuration, documentation, and container files for imports or runtime references
4. Targets with zero callers and no executable/package reachability were flagged as dead
5. Manual review excluded `py_binary` entry points, dynamically-loaded files (Alembic, Invoke), and targets where the name differs from the module name
